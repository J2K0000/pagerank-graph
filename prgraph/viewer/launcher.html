PageRank interne · cartographie du jus

Entrez l'adresse d'un site : il est crawlé (robots.txt respecté), le graphe nettoyé (301, canonical, 404, nofollow), le PageRank pondéré calculé, puis le rapport interactif s'ouvre.

Au-delà, le rapport est partiel : les pages non crawlées sont comptées comme des fuites.

Pages à pousser (optionnel)

Les URL que vous voulez positionner : articles qui rankent sur des requêtes business, offres, pages piliers. Une par ligne (URL complète, chemin, ou regex). Elles deviennent la priorité du rapport : classe money, cible d'alignement, tickets « Renforcer une cible choisie » avec les émetteurs du même silo. Modifiable ensuite dans l'onglet Cibles à pousser du rapport.

Données business

Croiser le PageRank avec la valeur des pages (chiffre d'affaires, conversions, clics, impressions). Les données sont lues sur cette machine ; les identifiants Google viennent de la variable GOOGLE_APPLICATION_CREDENTIALS, rien n'est stocké dans le projet.

Dimension page, type web, pagination par 25 000 lignes. Colonnes : clics, impressions, CTR, position. La famine est calculée sur les clics ; les impressions sont lues comme la demande.

Métriques : sessions, événements clés (conversions), revenu total. Les chemins sont préfixés par l'adresse du site pour redevenir des URL complètes.

Le crawl lit le HTML servi (pas de rendu JavaScript). Un site de 500 pages prend au moins deux minutes et demie avec le délai par défaut (une requête toutes les 0,3 s, quel que soit le nombre de requêtes parallèles). Pour un export Screaming Frog ou un CSV d'arêtes d'un autre crawler, utiliser la ligne de commande python -m prgraph compute.
